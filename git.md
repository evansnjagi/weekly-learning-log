# Git Learning
> Git is a version control system.

> GitHub is an online platform that hosts git projects on the internet. You can access the files  from anywhere, they are kept safe, and easy to share.
## 26-07-2026

### What I covered
Pushing staged files to a GitHub remote repository. Basically, the flow is simple. Stage changes made to a file or files, commit the changes, and push to GitHub repo.

Before pushing to GitHub, connect your local machine to GitHub, change branch name from master to main, and finally push the project to main. Use `git push -u origin main` so that you don't keep on setting main as origin.  

### Key insight
Working with WSL-Ubuntu is good and professional. To push projects online, get a git personal token that lasts for a month. For safety, never save it inside your project folder to make sure that the token is not pushed accidentally online.
