### What I covered
Eigenvector is a nonzero vector that when transformed by a matrix $A$, it only gets scaled by a scalling factor called an *eigenvalue*. We use $\lambda$ to represent the scalar value: eigenvalue.

The following equation is use to get both eigenvector and $\lambda$:
$$(A - \lambda I)\vec{v} = 0$$

The identity matrix ($I$) makes sure that the $\det(A - \lambda I)$ is always zero. This can be explained from the following perspectives:

1. $null(A - \lambda I) \neq \{0\}$
2. nullity $>$ 0
3. $det(A - \lambda I) = 0$

All the conditions are equivalent, stating that $A - \lambda I$ can't be inverted.
